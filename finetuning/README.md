# 全参数微调：完整训练集一轮，训练上下文 1,024 条

本页只说明通用实验协议，不包含特定模型的调用示例、训练入口或权重路径。数据包同时保留[直接推理与全参数微调](../README.md)两种方式。

## 训练方式

从预训练权重出发，开放全部可训练参数，使用完整训练集训练 **1 轮（1 epoch）**。每条训练样本恰好作为一次查询样本参与监督损失，不能只从完整训练池随机抽少量步骤就声称完成一轮。

1. 以种子 42 将完整训练集无放回打乱，依次取最多 128 条查询样本。
2. 每步从当前查询以外的训练行中，无放回抽取 **1,024 条带标签上下文**，确保上下文包含两个类别。上下文与查询在同一步内不重叠；上下文可在不同步骤复用。
3. 以查询样本的原始真实标签计算二分类交叉熵，反向传播并更新全部模型参数。不同模型按其 API 正确使用 logits 或类别概率。
4. 保留末尾不足 128 条的查询批，完整遍历一次训练集后立即结束，不再次打乱循环，不按固定优化步预算训练。

这里的“一轮”按**查询覆盖**定义。上下文参与条件输入，不额外计入查询覆盖次数，也不减少需要作为查询训练的样本数。验证／测试标签不得用于梯度更新。

## 两个数据集的设置

| 项目 | SGCC | VSB |
| --- | --- | --- |
| 数据位置 | `SGCC/data/` | `vsb/data/` |
| 输入特征 | 原始 1,034 个日用电量字段 | 作者 9 个特征 |
| 完整训练集 | 29,659 条用户 | 2,032 条三相测量 |
| 训练轮数 | 1 | 1 |
| 每步训练上下文 | 1,024 条 | 1,024 条 |
| 每步查询上限 | 128 条 | 128 条 |
| 一轮优化步数 | 232 | 16 |
| 最后查询批大小 | 91 | 112 |
| 完整验证集 | 6,356 条 | 436 条 |
| 验证主指标 | ROC-AUC | MCC |
| 分类阈值选择 | 验证 F1 最大 | 验证 MCC 最大 |
| 验证／测试固定推理上下文 | 原固定 2,048 条训练用户 | 全部 2,032 条训练测量 |

**1,024 指微调训练时每步的上下文大小。** 验证／测试仍沿用与直接推理相同的固定上下文，便于比较；SGCC 的 `context_2048.parquet` 不作为 1,024 条训练上下文的固定限制，每步应从完整训练集重新抽样。

## 参数与验证选择

- 全参数梯度更新；不使用 LoRA 或仅训练分类头。
- AdamW 学习率 `1e-6`、weight decay `0.01`、梯度范数裁剪 `1.0` 作为默认设置，运行前固定；不进行学习率搜索。
- 数据查询排列种子 42，上下文抽样种子 43。模型精度、设备、其余参数需由实际运行记录，避免把某个模型的默认设置当作统一约束。
- 保留原始类别比例和 NaN，不进行 SMOTE、类别加权或阳性过采样。预处理只在训练上下文上拟合。
- 训练前评估未微调检查点，完成这一整轮后再评估完整验证集。SGCC 按验证 ROC-AUC、VSB 按验证 MCC，在初始与一轮结束两个候选中选择权重；同分保留初始权重。
- 选择好权重后，在该检查点的验证概率上选择分类阈值，固定权重与阈值，最后评估测试集一次。

SGCC 必测 **ROC-AUC、PR-AUC（AP）、F1、窃电召回率**；VSB 以 **MCC** 为主，另报 ROC-AUC、AP、F1、阳性召回率。概率指标直接使用连续概率，不能按测试集选择阈值。

## 实现与核对

`training_schedule.py` 提供与模型无关的单轮查询排列，确保每条训练行恰好出现一次；`protocol.json` 保存统一实验协议。实际模型训练接口由实验代码实现，本目录不提供模型专用运行示例。

每次运行应在 `ele_sig` 外保存：模型与环境信息、数据哈希、训练查询行号及每行覆盖次数、上下文大小、优化步数、初始及单轮结束的验证概率、所选检查点与阈值，以及最终测试概率和指标。

`audit_run.py` 用于兼容其输出格式的运行目录：配置需记录 `epochs=1`、`context=1024`、`query=128` 及查询种子，结果需记录实际优化步数和 `completed_data_passes=1`。它核对单轮覆盖、验证选择、真实标签与最终指标。

本包保留数据、协议与通用核对工具，不含模型成绩、预测、日志或权重。本次协议修改不表示已按新设置重新训练。
